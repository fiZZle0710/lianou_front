# 华为 / 鸿蒙测试机安装指引

> 用途：把这一页直接发给用华为手机的测试同学。
> 适用包：`release\lianou-demo-*.apk`（内部测试包，包名 `com.lianou.app`，仅 `arm64-v8a`）
> 相关：`APK打包与真机联调.md`（打包流程）、`新人上手.md`

---

## 0. 先确认一件事：是「鸿蒙 4.x 及以下」还是「HarmonyOS NEXT 5.x」

**设置 → 关于手机 → 版本号 / HarmonyOS 版本**

| 看到的版本 | 能不能装 APK | 看哪一节 |
| --- | --- | --- |
| HarmonyOS 2.x / 3.x / 4.x、EMUI 9~12 | ✅ 能（底层仍是 Android） | 第 1~3 节 |
| **HarmonyOS NEXT 5.0 及以上**（"纯血鸿蒙"） | ❌ **完全不能**，与设置无关 | 第 5 节 |

判断小技巧：设置里如果出现「**纯血鸿蒙 / HarmonyOS NEXT**」字样，或应用商店里显示"鸿蒙原生应用"专区，就是 5.x。

---

## 1. 关掉「纯净模式」（华为装不上 APK 的第一原因）

华为默认开启纯净模式，会直接拦掉所有非应用市场来源的安装包，**且提示往往只说"应用来源未知"**。

| 系统 | 路径 |
| --- | --- |
| HarmonyOS 4.x | 设置 → 系统和更新 → 纯净模式 → **退出纯净模式**（需要输入华为账号密码） |
| HarmonyOS 3.x / 2.x | 设置 → 系统和更新 → 纯净模式 → 退出 |
| EMUI | 设置 → 安全和隐私 → 更多安全设置 → **外部来源应用下载** → 允许 |

> 找不到就在设置顶部搜索框搜「**纯净模式**」。
> 如果页面里有「**增强防护**」开关，一并关掉，否则退出纯净模式也会被它挡住。

---

## 2. 允许「安装外部来源应用」

设置 → 安全 → 更多安全设置 → **安装外部来源应用** → 找到「浏览器」和「文件管理」→ 打开允许。

（部分机型叫「特殊应用权限 → 安装未知应用」。）

---

## 3. 下载并安装

1. **用手机自带的华为浏览器**打开下载链接（不要用微信内置浏览器）。
2. 下载完成后华为会提示"该文件可能危害设备" → 点「**仍然下载**」。
3. 在下载管理里点开 APK → 点「安装」。
4. 弹出「**未经华为安全检测**」/「未知开发者」→ 点「**继续安装**」（可能要输锁屏密码）。
5. 装完桌面出现「莲藕」图标。

**常见报错对照：**

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 安装包损坏 | 下载不完整 | 重新下载，核对文件大小（约 14.6 MB） |
| 应用未安装 / 签名冲突 | 手机上已有同包名旧版 | 先卸载旧的「莲藕」再装 |
| 已阻止安装 / 此应用不安全 | 纯净模式没关干净 | 回第 1 节，确认「增强防护」也关了 |
| 与您的手机不兼容 | 极老的 32 位机型 | 把机型发给我们（本包仅 arm64） |

### 关于"未经安全检测"的说明（可直接转给测试同学）

> 这是内部测试包，用 DCloud 云端测试证书签名，**没有上架华为应用市场**，所以华为会提示未检测。
> 不影响任何功能，也不代表有病毒。正式版会走应用市场上架。

---

## 4. 装完打不开 / 闪退 / 白屏

| 现象 | 处理 |
| --- | --- |
| 首次打开白屏 3~5 秒后正常 | **正常现象**：这版是无后端演示包，启动时会先等接口失败再回退本地演示数据 |
| 一直白屏 / 一直转圈 | 手机管家 → 应用启动管理 → 莲藕 → 允许「自启动 / 关联启动」；手机管家 → 流量管理 → 应用联网 → 允许 WLAN 与移动数据 |
| 打开就闪退 | 记录机型 + 鸿蒙版本 + 闪退时机，发截图/日志给我们 |
| 提示"检测到风险应用，已限制部分权限" | 手机管家 → 病毒查杀 → 找到莲藕 → 选择「信任」；或设置 → 应用 → 应用管控中心 → 解除管控 |
| 桌面图标是白块/默认安卓机器人 | 系统缓存，重启手机后恢复 |

确认装的是我们的包而不是调试基座：设置 → 应用 → 应用管理 → 搜「莲藕」→ 查看包名应为 **com.lianou.app**。

---

## 5. 如果手机是 HarmonyOS NEXT 5.x

**APK 装不上不是设置问题，是系统层面不兼容 Android 应用**，任何"允许未知来源"都没用。三条路：

| 方案 | 说明 | 成本 |
| --- | --- | --- |
| A. 换一台设备 | 找一台 HarmonyOS 4.x 及以下、或任意安卓机测试 | 0，最快 |
| B. 用 H5 网页版 | 同一套代码打包成网页，华为浏览器直接打开即可测 UI 与交互；需要一个可公网访问的地址（GitHub Pages / 内网穿透任选） | 小，我可随时出 |
| C. 出鸿蒙原生包（.hap） | 需要 DevEco Studio + 华为开发者账号 + 调试证书，工程里已带 `@dcloudio/uni-app-harmony`，但证书申请与签名链要单独配 | 大，暂不建议 |
