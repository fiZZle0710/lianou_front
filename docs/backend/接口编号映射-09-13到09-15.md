# 接口编号映射：09-13 版 → 09-15 版

> **用途**：2026-09-14 写的几份前端文档引用的是 **09-13 旧版**（`archive/API-2026-09-13.md`）的**全局编号** `#1`…`#96`；09-15 新版改成了**按模块局部编号**。本表用于换算与复核。
> **新约定**：今后引用接口一律写「方法 + 路径」，编号只作辅助（后端下次重排编号，我们不必再重映射一遍）。
> **数据来源**：脚本解析两份文档的「接口汇总表」，按 `方法 + 归一化路径` 匹配（`<int:xxx>` / `<xxx>` 统一视作 `{id}`）。结果：旧 96 条 **100% 命中**，新版 **零删除**（96 + 10 = 106，接口集合上是严格超集）。

## 一、编号规则对照

| | 09-13 版 | 09-15 版 |
|---|---|---|
| 编号方式 | 全局连续 `#1` … `#96` | 按模块局部（12 个模块各自从 1 开始） |
| 正文标注 | `### 59. POST /api/v1/...` | `#### 5.8 POST /api/v1/...`（`模块.序号`） |
| 接口总数 | 96 | 106 |

**不是平移关系**：旧 `#1`=login、`#2`=logout、`#3`=me、`#5`=register、`#7`=send-code；
新 `1.1`=send-code、`1.2`=register、`1.3`=login、`1.6`=me、`1.7`=logout。
