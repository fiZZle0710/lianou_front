## C. 缺功能（后端目前没有实现，多数要动表结构）

### 1. 收藏 / 收藏集 —— **最大的洞**
- **UI 出处**：
  - `components/common/WorkCard.vue` 作品卡右上角「收藏」角标
  - `pages/feed/detail/index.vue` 底部「收藏 / 已收藏」
  - `pages/history/index.vue` 底部「收藏 (N)」批量收藏
  - `components/mine/ContentTabs.vue` 「我的」→「收藏」tab、`＋ 创建新收藏集`、收藏集封面 + "N 个作品"
- **现状**：`DATABASE-2026-09-15.md` 的 37 张表里**依然没有任何 favorites / collections 之类的表**；106 个接口里也没有任何收藏接口 → ❌ **09-15 版仍未解决，本清单最大缺口**
- **需要新增**：收藏关系表（`user_id` + `work_id`）、收藏集表（名称/封面/所属用户/可见性）、收藏集-作品关联表
- **需要接口**：收藏 / 取消收藏、我的收藏列表、收藏集增删改查、批量收藏

### 2. 分享
- **UI 出处**：`pages/feed/detail/index.vue`「分享」+ 分享渠道弹窗（微信 / 站内分享）、`components/mine/ContentTabs.vue` 发布成功后的「站内分享」引导
- **现状**：只有 `works.share_count` 一个计数字段，无表（B-7 是它的最小版本；要做"谁分享的/分享去向"就需要表）
- ⏸ **09-15 答复：后端明确「暂缓」** —— 只提供 `POST /works/<id>/share`（**3.15**）做计数，分享记录表不做（见 `docs/backend/2026-09-15-需求实现说明.md` 需求 8）→ 前端按「只计数」实现即可

### 3. 搜索用户 / 项目
- **UI 出处**：`pages/search/index.vue`，输入框 placeholder 写的是「搜索作品、**用户**...」
- **现状**：✅ **用户搜索已实现**：`GET /api/v1/users/search`（**12.1**，关键字 + 分页）；作品搜索 = **3.12**；❌ **项目搜索仍没有**

### 4. 账号与安全页的 6 项
- **UI 出处**：`pages/account/index.vue` —— 手机号 / 密码 / 邮箱 / 设备管理 / 黑名单 / 切换账号 / 退出登录
- **现状**：
  - 改密码、换手机号：API 只有「忘记密码 `reset-password`」，**没有登录态下的修改接口**
  - **邮箱**：`users` 表里**没有 `email` 字段**，需要加列
  - 设备管理（登录设备列表 / 踢下线）：无表、无接口
  - 黑名单：无表、无接口（`work_visibility_rules` 是作品级，不是用户级）
  - 切换账号：纯前端行为，可忽略

### 5. 我的专业程度
- **UI 出处**：`pages/level/index.vue` ——「我是专业的！/ 我是萌新」
- **现状**：DB 里 `profiles.identity` 是 NOT NULL（`professional` / `amateur`），但 API 里找不到设置它的接口 → **请确认 `PUT /profile/me` 是否接受 `identity`**

### 6. 作品浏览数上报
- **UI 出处**：`pages/feed/detail/index.vue` 的「👁 浏览 N」；`pages/history/index.vue` 浏览记录
- **现状**：有 `work_view_history` 表和 2.5 / 2.6 读取接口（09-15 又加了 **2.7** 删除接口），但仍**没看到"浏览数 +1"的接口** → 请确认是否由 `GET /works/<id>` 自动累加（09-15 版未答复）
