## 四、前端待改清单（按依赖顺序）

1. **`src/utils/config.js`**：`BASE_URL` 补 `/api/v1`；`UPLOAD_URL` 与真实上传路径对齐（当前 `'/api/upload'` 三个上传接口都不匹配）；真机调试把 `127.0.0.1` 换成开发机局域网 IP（手机上 `127.0.0.1` 指向手机自身）；上线前把 `DEBUG` 关掉。
2. **`src/api/*.js`**：按第二节重写为真实路径 + snake_case 参数；私聊拆成"建会话 → 拉消息"，`sendMessage` 拆成私聊 / 群聊两个；补齐实际用到的接口（约 50 个 / 新版共 106 个）。**建议等后端给 OpenAPI 或补完 P0-1 后一次性生成**，避免写两遍。
3. **上传链路**：`src/utils/upload.js` 的封装可复用，只需把默认 `url` 从 `/api/upload` 改为真实路径（`/api/v1/works/upload` 等）；字段名已由 09-15 版文档确认**就是 `file`**（与现默认值一致，无需改）；发布流程改为「上传 → `POST /works/` → `POST /works/<id>/publish`」。`publish/*` 页目前只 toast 成功，需接真实链路。
4. **登录 / 注册**：`login` 改 `POST /auth/login` 且传 `phone`；注册改接 `send-code` + `register`，删掉 `TEST_SMS_CODE` 分支（或仅 `DEBUG` 下保留）。
5. **`request.js`**：错误处理改为按业务 `code` 映射文案（等后端 P0-4 错误码表）；401 加防抖，避免并发多请求重复跳登录页。
6. **`feed/detail`**：点赞、评论、关注按钮目前是假数据，需接 4.1 / 4.2 / 4.3 / 4.4 / 4.5 / 10.1 / 10.2。
7. **时间显示**：后端返回**无时区后缀**的 UTC 时间（如 `2026-09-15T10:30:00`），JS 的 `new Date()` 会按**本地时间**解析 → 所有时间展示统一按 UTC 处理，否则差 8 小时。
8. **H5 预览**：后端 CORS 已确认 `origins: *`，`npm run dev:h5` 直连即可、无需代理；`request.js` 的错误分支可按 09-15 版的 55 条错误码表映射（6 条通用 + 1xxx~6xxx 共 49 条业务码，见该文档第五节）。

- `DEBUG_FALLBACK`（默认 `true`）：**只对「读」接口**失败回退 `src/mock`，页面右上角显示「演示数据」灰标；
